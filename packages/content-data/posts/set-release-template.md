## The set at a glance

Name the set, its release date and the date it becomes tournament legal. Add the set to `data/sets.yaml` and set `set: <code>` in this post's frontmatter: the post then appears on that set's page and the timeline.

## Cards that matter

Pick the three to five cards that will see play. For each one:

- **[Card]:** which deck it goes in, what it replaces, and the matchup it changes.

Skip the full set review. Readers come here to find out what to test.

## Decks that gain

Which archetypes get better, and by how much. Link each one's Deck Dex entry so readers can see the current list.

## Decks that lose

New cards also create new counters. Say which decks now face a worse field, and whether that's enough to drop them.

## What to test first

End with a short list of the builds or techs you'll test before the first event where the set is legal.
